# 🚀 MERN Stack CRM Application

A full-stack Customer Relationship Management (CRM) application built with the MERN stack, featuring secure authentication, CRUD operations, and cloud deployment.

## ✨ Features

### 🔐 Authentication

- Secure user registration and login
- JWT-based authentication
- Password hashing with bcrypt
- Protected routes (frontend & backend)
- Token refresh mechanism
- Rate limiting for login attempts (3 attempts per 10 minutes)

### 👥 Contact Management

- Complete CRUD operations for contacts
- Search functionality (by name or email)
- Filter by status (Lead, Prospect, Customer)
- Pagination (10 items per page)
- CSV export functionality
- Activity logging for add/edit/delete events

### 🎨 User Interface

- Responsive Material-UI design
- Form validation
- Loading states and error handling
- Intuitive dashboard layout

## 🛠️ Tech Stack

- **Frontend:** React.js, Material-UI, React Router, Axios
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **Authentication:** JWT, bcrypt
- **Testing:** Jest, React Testing Library, Supertest
- **Deployment:** Vercel (Frontend), Railway (Backend)
